# 실물 라쿤봇: 컵 정면 파지 벤치 테스트

컵을 옆에서 잡는 수평 자세로 접근하고, 닫은 뒤 2cm 들어 올리는 rule-based 코드입니다.
시뮬레이션의 고정 좌표나 관절값을 실물에 복사하지 않습니다. 실제 로봇에서 파지 위치를 한 번 맞춰 저장합니다.
카메라/VLM/ACT는 사용하지 않습니다. 컵 한 개의 접근 경로가 비어 있는 작업대에서 사용합니다.
처음에는 액체 없는 가벼운 모형 컵을 사용하세요. 로봇 전원 차단 수단을 손이 닿는 곳에 두세요.

## 1. 파일 위치와 VSCode 환경
이 폴더 전체를 ~/Raccoonbot_Openvla/raccoon_real_cup 에 넣습니다.
새 VSCode 터미널에서:

```bash
conda create -n raccoon-real python=3.11 -y
conda activate raccoon-real
cd ~/Raccoonbot_Openvla
python -m pip install "roboid==1.7.3"
```
이미 raccoon-real 환경을 만들었다면 create는 생략합니다.
SDK 1.7.3의 코드와 공식 문서를 기준으로 만들었습니다. 다른 버전이면 로봇 생성 전에 종료합니다.
roboid 1.7.11은 생성자에서 초기 자세 동작을 호출하고 함수/좌표 기준도 바뀌었으므로 임의로 버전을 올리지 마세요.
시뮬레이션/VLM 환경은 수정하지 않습니다.

## 2. 연결 확인 (동작 명령 없음)
로봇 전원을 켜고 USB-BLE 동글을 연결합니다. 다른 로봇 제어 프로그램은 닫습니다.

```bash
python raccoon_real_cup/cup_pick_real.py --read
```
이 모드는 관절각과 기구학으로 계산한 손목 좌표만 출력합니다. 초기 자세로 이동하는 명령은 없습니다.
자동 연결이 안 되면 아래로 동글 포트를 확인하고 실제 포트를 명시하세요.

```bash
python -m serial.tools.list_ports
python raccoon_real_cup/cup_pick_real.py --port /dev/ttyUSB0 --read
```
/dev/ttyUSB0은 예시입니다. 출력된 동글 포트를 쓰세요.
Permission denied가 뜨면 먼저 해당 포트 소유 그룹을 확인하세요. dialout 그룹인 경우:

```bash
sudo usermod -aG dialout "$USER"
```
로그아웃/로그인 후 다시 실행합니다. 전체 VSCode를 sudo로 실행할 필요는 없습니다.

## 3. 위치 맞추기
```bash
python raccoon_real_cup/cup_pick_real.py
```
명시 포트가 필요하면 같은 --port 옵션을 붙이세요.
프롬프트가 raccoon>로 바뀌면 아래 명령은 Python 코드가 아니라 이 프로그램 안의 명령입니다.
각 줄 입력 후 Enter를 누릅니다.

컵과 장애물을 먼저 치워두세요. 그리퍼가 회전할 공간을 확보한 상태에서:

```text
open
horz
status
```
horz는 현재 손목 위치에서 그리퍼를 수평으로 돌립니다. 이때 실제로 움직입니다.
수평의 기준은 지면이며, 로봇 베이스 회전에 따라 좌우 방향은 달라집니다.

그리퍼가 컵 몸통을 양쪽에서 잡을 위치까지 아래처럼 조금씩 맞춥니다:

```text
jog y 0.2
jog z -0.2
jog x 0.2
```
각 명령은 해당 축으로 0.2cm(2mm) 이동합니다. 한 번에 최대 ±0.5cm입니다.
이 예시는 각 축 사용법이며 세 줄을 무조건 전부 실행하라는 뜻이 아닙니다.
반대 방향은 음수입니다. q1=0일 때 +y가 로봇 정면, +z가 위쪽입니다.
x의 좌우는 로봇을 바라보는 방향과 다르므로 작은 이동을 관찰하며 확인하세요.
좌표는 '손목 중심' 기준입니다. 컵 중심이나 집게 끝 좌표로 착각하지 마세요.
실제 컵/3D 출력 파지부와 그리퍼가 맞물릴 위치를 눈으로 맞추는 과정입니다.

수평이 불가능한 관절 범위 또는 펴진 특이 자세라면 명령이 거부됩니다.
관절을 손으로 억지로 꺾지 마세요. 컵 없는 공간에서 다음처럼 1도씩 초기 자세를 조절할 수 있습니다:

```text
joint 2 -1
joint 3 -1
horz
```
joint는 일반 관절 조그라 수평을 유지하지 않습니다. 최대 ±2도이며, 컵 없는 초기 세팅에서만 사용합니다.

## 4. 파지 위치 저장 → 후퇴 → 컵 배치
집게를 열어 둔 채 컵 몸통을 잡을 위치를 맞췄다면:

```text
mark
retreat
```
mark는 현재 손목 위치를 cup_pose.json에 저장하고 접근/상승 경로의 기구학을 검사합니다.
retreat는 지면과 수평인 채 베이스 쪽으로 2cm 후퇴합니다.
그 다음, 원래 mark 위치에서 집게가 컵 몸통을 감쌀 수 있도록 컵을 놓습니다.
컵의 바닥 위치를 작업대에 표시하면 반복하기 편합니다.

```text
pick
```
실제 동작: 그리퍼 열기 → 저장 위치까지 수평 접근 → 닫기 → 수평 유지하며 2cm 상승.
현재 위치가 지정 접근 위치에서 5mm 이상 벗어나면 자동 실행하지 않습니다.
파지/상승 완료 메시지는 명령 완료입니다. 컵을 실제 잡았는지는 눈으로 확인해야 합니다.

```text
lower
```
실제 동작: 원래 높이로 내려놓기 → 그리퍼 열기 → 2cm 후퇴.
이후 pick/lower로 반복할 수 있습니다. 프로그램 종료는 quit입니다.
컵을 잡은 상태에서 종료하면 지지 상태가 달라질 수 있으므로 먼저 lower로 내려놓으세요.
Ctrl+C는 stop()을 요청합니다. 통신 단절 시 소프트웨어 정지 요청이 도달하지 않을 수 있습니다.

## 5. 다음 실행
load는 저장한 목표만 읽으며 자동 이동하지 않습니다.
새 실행에서 임의 위치에서 컵으로 자동 접근하지 않습니다. 먼저 빈 공간에서 horz와 jog로 접근 위치에 맞추세요.
로봇/컵/작업대 위치가 달라지면 기존 값을 재사용하지 말고 다시 mark 하세요.
속도 기본값은 SDK 스케일 10입니다(mm/s가 아님). 필요하면 --speed 5로 더 낮출 수 있습니다.
--lift-cm 1 --retreat-cm 1로 조정 가능하나, mark와 실행 때 같은 설정을 유지하세요.

## 구현 및 검증 범위
- SDK 1.7.3의 손목 기구학과 같은 축/링크 길이(8.25,10,10cm)를 사용합니다.
- q4=-90-q2-q3으로 수평 자세를 계산하고 unlock 상태에서 4개 목표 관절각을 함께 보냅니다.
- Cartesian 경로를 1mm 간격의 중간 목표로 나눕니다. 실제 서보 보간/오차 때문에 완벽한 직선·수평을 보장하지 않습니다.
- 관절 한계, 유효 숫자, IK 도달 가능성, 중간 목표 급변, 연결 상태, 도착 timeout을 검사합니다.
- 관절 목표 도착 오차 1도, 최종 손목 위치 허용 오차 5mm는 초기 테스트 설정이며 정밀 파지 성능을 보장하지 않습니다.
- 책상·컵·로봇 링크 충돌/파지력/낙하를 감지하지 않습니다. 카메라 캘리브레이션, 자동 컵 탐색은 포함하지 않습니다.
- 소프트웨어 테스트 6개 통과. SDK 순/역기구학과 967개 자세 수치 비교 통과.
- 테스트는 계산 및 가상 장치 검증입니다. 실물 연결/컵 파지는 제작 환경에서 검증하지 않았습니다.
