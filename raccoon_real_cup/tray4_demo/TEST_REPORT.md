# 오프라인 검증 결과

결과: **자동 테스트 27개 통과**. 실제 로봇/RealSense는 연결하지 않았습니다.

검증한 항목:

- 네 물체의 24가지 순서에 대해 전체 계획 생성, 관절 범위·자세 전환·시작 자세 복귀 검사. 과거 좌표로 만든 테스트 배치와 예시 시작 자세를 사용했습니다.
- 접시와 두 컵의 붓기 왕복 두 번, 유리컵 배치 시 q4만 하향 회전, 모든 물체의 놓기/복귀 포함.
- 제공된 roboid 1.7.3 원본 메서드를 대기 함수만 모킹하여 실행한 결과와, 새 비동기 어댑터의 최종 장치 명령값 비교: 수평 이동, q4 회전/집게 닫기, 수직 이동 일치.
- 가상 로봇의 관절 피드백으로 네 물체 전체 동작을 완료하고, 10Hz 관측-action과 20Hz 관절 읽기 로그의 정렬 검사.
- 동작 종료 후 터미널 대기에 해당하는 원본 프레임 보존과 학습 표본 제외. Action chunk가 물체 구간 경계를 넘지 않음.
- 실제 camera worker에 가상 RealSense/검출기를 주입: 순서 확정 뒤 검출기 호출 중단, 저장 PNG 픽셀이 입력 원본과 동일함.
- 트레이 아래 변 중앙 기준 거리순 정렬, 재질 분류, 트레이 마스크 구멍 보완, 네 물체 누락/불확실/중복 검출 처리.
- 연결 단절 처리 경로, 시간 초과, 부적절한 자세 전환, 오래되거나 미래 시점인 관절 표본 거부.
- 집게 명령과 실제 미측정 집게 상태 구분, 라디안 변환, 목표 명령과 mode 보존.
- 모의 데이터는 실제 성공 데모로 내보내지 않음. 변환기는 테스트용 통과 보고서를 주입한 별도 검사에서 5D state/8D action/네 구간의 NPZ를 생성함.
- 설치가 기존 파일을 덮어쓰지 않음. 네 위치 입력·24순서 검사·`--execute` 없는 명령에서 하드웨어에 연결하지 않음.
- Python 문법 검사와 동봉된 기존 동작 코드 사본의 SHA-256 일치 확인.

재현 명령:

```bash
python -m unittest discover -s tests -v
```

OpenCV/numpy가 없는 환경은 영상 테스트 일부를 건너뛸 수 있습니다. 이 배포본의 전체 27개 검사는 OpenCV와 numpy를 설치한 테스트 환경에서 실행했습니다.

검증하지 않은 항목:

- 실제 현재 배치에서의 파지, 음식물·액체 배출, 유리컵 배치, 충돌 여유
- 실제 USB/전원/펌웨어의 연결 안정성과 모터 응답 시간
- 사용자의 PC에서 실제 RGB 10Hz와 encoder 읽기 20Hz가 유지되는지
- 학습된 ACT 모델의 성공률 또는 일반화 성능

실제 실행에서는 입력한 이번 배치 좌표와 읽은 현재 시작 관절로 다시 계획을 검사합니다. 첫 실제 에피소드의 동작 결과 및 `audit.json`까지 확인해야 실제 수집 품질을 판단할 수 있습니다.
